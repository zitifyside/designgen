## 1. 문서 개요

. 목적 : AI Design Generator 서비스의 모든 기능 요구사항을 ID 체계로 정의하여, 후속 산출물(기획서·기능정의서·서비스정책서·기술명세서·테스트케이스)의 단일 진입점(Single Entry Point)으로 기능하게 한다.

. 대상 사용자 : Guest, Free, Pro, Team, Admin 5등급이다.
. Touch Point : Figma Plugin, Web App, Public API, MCP Server 4종이다.

## 4. 요건 상태 정의

| 상태 | 정의 |

| 신규 | 최초 등록 상태. 확인 필요 사항이 남아 있다. |

| 철회 | 요건이 취소되었다. 삭제하지 않고 철회 사유를 비고에 기술한다. |
